Learning Objectives

By the end of this topic, you'll be able to:

  • Explain what it means for code to make a decision.
  • Write an if / elif / else statement.
  • Use comparison operators (==, >, <, >=, <=, !=).
  • Combine conditions with and / or.

Key Vocabulary

Conditional
code that runs only when a certain condition is true.
Boolean
a value that is either True or False.
Comparison operator
a symbol like == or > used to compare two values.
and / or
words used to combine more than one condition into a single check.
