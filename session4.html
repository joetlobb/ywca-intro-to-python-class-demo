Learning Objectives

By the end of this topic, you'll be able to:

  • Explain why loops save time and reduce repeated code.
  • Write a for loop using range().
  • Write a while loop with a clear stopping condition.
  • Recognize and avoid an infinite loop.

Key Vocabulary

Loop
code that repeats a set of instructions multiple times.
for loop
repeats a fixed number of times, or once for each item in a list.
while loop
repeats as long as a condition stays true.
range()
generates a sequence of numbers, often used to control how many times a for loop runs.
Infinite loop
a loop whose stopping condition is never met, so it runs forever.
