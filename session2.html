Learning Objectives

By the end of this topic, you'll be able to:

  • Store information in a variable and explain why that's useful.
  • Tell the difference between text (strings) and numbers.
  • Use input() to get information from the person using your program.
  • Combine variables and text using an f-string.

Key Vocabulary

Variable
a named container that holds a piece of information so you can use it later.
String
text data, always written inside quotes, like "hello".
Integer / float
whole numbers (integers) and numbers with decimals (floats).
input()
a function that pauses the program and waits for the person using it to type something.
f-string
a shortcut for building text that includes the value of a variable, written as f"...".

input() lets your program ask a question and wait for the person using it to type an answer, instead of you hard-coding the value yourself.

Common Mistakes to Watch For

  
    
    
  • Forgetting the f right before the opening quote when trying to use {variable} inside text.
    • 
    
  • Trying to do math directly on an input() value without converting it to a number first — "3" + "4" gives "34", not 7.
    • 
    
  • Mismatched variable names — Python is case-sensitive, so Name and name are two different variables.
