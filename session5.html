Learning Objectives

By the end of this topic, you'll be able to:

  • Create and update a list.
  • Access items in a list by position.
  • Define a simple function with def and call it.
  • Explain why breaking code into functions makes it easier to read and reuse.

Key Vocabulary

List
an ordered collection of values, written in square brackets, like ["a", "b", "c"].
Index
the position of an item in a list, starting from 0.
Function
a named, reusable block of code that performs a specific task.
Parameter / argument
a value passed into a function so it can use it.
Return value
the result a function sends back after it runs.

  • Forgetting return in a function and being confused why the result prints as None.
