Learning Objectives

By the end of this session, you'll be able to:

  • Explain, in your own words, what a computer program is.
  • Run your first line of Python code.
  • Use the print() function to display a message.
  • Recognize and fix a basic error message.

Key Vocabulary

Program
a list of instructions a computer follows, in order, one at a time.
Code
the instructions themselves, written in a language the computer understands.
Python
one of many programming languages — known for reading almost like plain English.
Run
to have the computer actually carry out the instructions in your code.
Syntax error
a mistake in how code is written — like a typo or missing punctuation — that stops the program from running.

Common Mistakes to Watch For

  
    
    
  • Using “smart quotes” pasted from Word or Google Docs (“ ”) instead of straight quotes (" ") — Python won't accept curly quotes.
    • 
    
  • Forgetting the closing parenthesis or quotation mark.
    • 
    
  • Typing Print with a capital P — Python is case-sensitive, so it must be print.
